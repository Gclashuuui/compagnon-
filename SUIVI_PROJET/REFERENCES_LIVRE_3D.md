# Références du ZIP 3D

L'archive de références contient les dossiers complets des 22 thèmes présents dans
le mod. Les textures montrent la direction artistique, les couleurs et les motifs.

Elles ne constituent pas un patron UV de livre fermé. Le futur modèle doit posséder
son propre atlas 128 x 128, commun à toutes les variantes.

## Thèmes HD

- `sylvestre_hd`
- `observatoire_hd`
- `nuages_hd`
- `lucioles_hd`
- `marees_hd`
- `confiserie_hd`
